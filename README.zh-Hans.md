# 守桥者：脉冲防线 — 技术支持

[English](README.md) · [隐私政策](PRIVACY.md)

守住桥梁，护送最后一支撤离车队回家。

由 Zhenqing Hou 开发的离线 iPhone 小队防守游戏，包含三个章节、24 个任务。

## 玩法

- 左右拖动控制小队走位，队员会自动射击。
- 击破补给箱，在波次间选择升级，招募队员并增强武器。
- 躲开有标记的攻击。直接命中会减员，可通过后续补给重建小队。
- 在敌人逼近时使用脉冲，注意冷却时间。
- 各关首领的装备与攻击组合不同，可在敌情情报查看战术和故事。

## 常见问题

**需要联网或登录吗？** 不需要。游戏没有广告或 App 内购买。

**如何切换语言？** 英语与简体中文会跟随 iPhone 语言设置；启用多种语言后，也可在 iOS 设置中选择单个 App 的语言。

**进度保存在哪里？** 关卡和星数保存在当前设备，不使用开发者运营的云同步。删除 App 会移除本地进度。

**如何关闭音乐或触感？** 从任务页面或暂停页面进入设置，分别调整音乐、音效和触感。

**如何查看隐私政策？** 在设置 → 隐私与支持中可离线阅读，也可打开上方链接。
